## 5. 结论

### v2 改进是否改善了 Elo？

**是，显著改善。** 虽然 v2 的 Elo 点估计（+3.5）在统计上不显著（CI 包含 0），
但与 v1 的 -85.7 相比是质的飞跃：

- **v1**：训练后网络明显**劣化**（-85.7 Elo），SPRT 在 401 局就判定 FAIL，
  说明无正则化 + 高学习率 + 小数据量导致 fc_2 过拟合，网络棋力退化。
- **v2**：训练后网络**不再退化**（+3.5 Elo ≈ 0），SPRT 跑满 500 局无法判定 FAIL，
  说明 L2 正则化（wd=1e-4）+ 10⁶ 数据 + lr=1e-3 成功抑制了过拟合。

### 改进归因

| 改进因素 | 作用 |
|------|------|
| L2 正则化 (wd=1e-4) | **主要功劳**：约束 fc_2 权重范数，防止过拟合导致的退化 |
| 10⁶ 数据量（vs 63K） | 提供更充分的梯度信号，减少小样本噪声 |
| lr=1e-3（vs 1e-2） | 更保守的步长，配合正则化更稳定收敛 |

### 情景判定

当前 v2 Elo = +3.5 ≈ 0，属于**"正则化成功避免了退化，但未提升棋力"**这一情景。
方向完全正确（从 -85.7 到 +3.5），但 fc_2 单层训练的表达能力天花板有限，
难以在持平基础上进一步获得正向棋力提升。

## 6. 下一步建议

### 短期（提升统计置信度）
1. **增加对弈局数至 2000-5000 局**：当前 500 局 CI=±30.5 过宽，
   2000 局可使 CI 收窄至约 ±15，5000 局约 ±10，方能可靠检测 ±10 Elo 的差异。
2. **提高每局节点数至 50000**：10000 节点下和棋率 43.4% 偏高，
   更多节点可降低和棋率，增加区分度。

### 中期（突破 fc_2 单层天花板）
3. **解冻 fc_1 联合训练**：fc_2 仅是输出层前的瓶颈层，单独训练它只能微调评分尺度。
   解冻 fc_1 可让中间表示也参与调整，表达能力显著提升。
4. **解冻部分 feature transformer**：进一步释放网络容量，但需配合更强正则化与更小学习率。
5. **尝试更小 L2（wd=1e-5）或 dropout**：当前 wd=1e-4 可能略强，抑制了有用信号，
   可做正则化强度扫描。

### 长期（训练范式升级）
6. **改用 SPSA 或 CMA-ES**：对 NNUE 这种高维非凸问题，黑盒优化可能比梯度下降更有效，
   尤其在仅训练末层时。
7. **引入 self-play 数据迭代**：用当前网络生成新对弈数据，迭代训练-对弈闭环，
   逐步提升棋力而非仅拟合静态数据集。
8. **差分进化 + 多种子集成**：训练多个独立种子的网络，取 Elo 最优或做权重平均。
